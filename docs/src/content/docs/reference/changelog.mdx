## v0.1.1 <Badge text="Latest" variant="success" />

**Released:** February 2, 2025

### Added
- Automated release workflow (creates GitHub releases on tag push)
- Changelog page in documentation site
- Custom inline theme toggle (Light/Dark/System buttons)

### Fixed
- Card hover effect on homepage (subtle border glow instead of scale)
- Lighthouse CI base path configuration
- Lychee link checker offline mode

### Changed
- Theme selector from dropdown to inline button group

## v0.1.0 <Badge text="Initial" variant="note" />

**Released:** February 1, 2025

### What's New

<Steps>
1. **Project Foundation**
   - Monorepo structure for multiple plugins
   - Git repository with proper `.gitignore`

2. **Documentation Site**
   - Astro + Starlight framework
   - Tailwind CSS for responsive design
   - Custom inline theme toggle (Light/Dark/System)
   - Full-text search with Pagefind

3. **WordPress Agent Skills**
   - 13 skills installed for Claude Code
   - Plugin development, blocks, REST API, security, and more

4. **CI/CD Pipeline**
   - GitHub Actions workflows
   - Lychee link checker
   - Lighthouse CI audits
   - PHP syntax validation
   - Automatic GitHub Pages deployment
</Steps>

### Technical Details

| Component | Technology |
|-----------|------------|
| Docs Framework | Astro 5.x + Starlight |
| Styling | Tailwind CSS 4.x |
| Hosting | GitHub Pages |
| CI/CD | GitHub Actions |
| AI Assistance | Claude Code + WordPress Agent Skills |
