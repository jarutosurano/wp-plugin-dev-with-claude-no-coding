## Documentation Commands

    cd docs && npm run build

    cd docs && npm run preview

## WordPress Testing

### WP Playground (Browser)

No installation needed - visit [playground.wordpress.net](https://playground.wordpress.net)

### WP-CLI Commands

```bash
# Install plugin from zip
wp plugin install ./plugins/my-plugin.zip --activate

# List all plugins
wp plugin list

# Check plugin status
wp plugin status my-plugin

# Deactivate plugin
wp plugin deactivate my-plugin

# Generate plugin scaffold
wp scaffold plugin my-plugin
```

## Claude Code Commands

```bash
# Start Claude Code in project directory
claude

# Start with specific context
claude "help me develop a WordPress plugin for..."

# Resume previous conversation
claude --resume
```

## GitHub Actions

```bash
# View workflow runs
gh run list

# View specific run details
gh run view [run-id]

# Manually trigger workflow
gh workflow run [workflow-name]
```

## Plugin Development

### Create New Plugin Structure

```bash
# Create plugin directory with standard structure
mkdir -p plugins/my-plugin/{includes,assets/{css,js},languages}
touch plugins/my-plugin/my-plugin.php
touch plugins/my-plugin/readme.txt
```
