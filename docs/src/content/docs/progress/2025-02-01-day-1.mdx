## What I Learned

### Monorepo Approach

Using a single repository for multiple plugins is called a **monorepo** - an industry-standard approach used by companies like Google and Meta. Benefits:

- Single source of truth for all work
- Easy cross-referencing between lessons
- Shared documentation and testing infrastructure

### WordPress Agent Skills

Installed 13 WordPress-specific skills that help Claude AI understand:
- WordPress coding standards
- Security best practices
- Plugin architecture patterns
- Block development
- REST API design

<Aside>
  Skills are stored in `.claude/skills/` and are automatically loaded by Claude Code.
</Aside>

### Documentation Stack

Chose **Astro + Starlight** over Jekyll because:
- First-class Tailwind CSS support
- Built specifically for documentation
- Fast static site generation
- Modern developer experience
